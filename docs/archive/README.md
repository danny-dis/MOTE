# Historical design and evidence archive

These documents are preserved for provenance, **not** as current product instructions,
live system status, or commitments to ship a roadmap. Dates, machine paths, API sketches,
provider results, and architecture diagrams reflect their original context. Commands
may reference unavailable services or old repository locations. Do not run them as a
current installation guide.
