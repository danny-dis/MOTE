01 / THE EXECUTION LOOP

A small core.
A clear job.

Models propose actions. MOTE checks the granted capabilities, runs the tool, and returns the observation. Repeat until the run completes or a limit is reached.

INTEGRATION SKETCH
from mote_sdk import Client, Tool

result = Client(binary="./mote-bridge").run(
    manifest={
        "name": "my-agent",
        "capabilities": ["uppercase"],
        "models": [{
            "provider": "openai-compatible",
            "model": "your-model",
            "endpoint": "http://localhost:8080/v1/chat/completions",
        }],
    },
    task='Call uppercase with {"text":"hello"}, then complete.',
    tools={"uppercase": Tool(
        "Input: text string. Return uppercase text.",
        lambda data: data["text"].upper(),
    )},
)
# Inspect result.events and validate your output.
import { Client } from "@mote-agent/sdk";

const result = await new Client({
  binary: "./mote-bridge",
}).run({
  manifest: {
    name: "my-agent",
    capabilities: ["uppercase"],
    models: [{
      provider: "openai-compatible",
      model: "your-model",
      endpoint: "http://localhost:8080/v1/chat/completions",
    }],
  },
  task: 'Call uppercase with {"text":"hello"}, then complete.',
  tools: { uppercase: {
    description: "Input: text string. Return uppercase text.",
    handler: ({ text }) => String(text).toUpperCase(),
  } },
});

A FEW THINGS WORTH KNOWING

Straight answers.

Is MOTE an AI model?

No. MOTE is the execution engine. You connect a supported model provider or local endpoint. Provider access, credentials, costs, and model quality are separate from MOTE.

Do I need to install Rust?

Not for the downloadable CLI or bridge. Python and TypeScript applications can use a prebuilt bridge. You need a Rust toolchain to compile from source or embed the Rust library.

Can it run untrusted code safely?

Not by itself. Capabilities limit what MOTE is allowed to invoke, but shell commands and application callbacks retain host privileges. Use an isolated account, container, or VM appropriate for your workload.

Are tool callbacks and events live?

Tool callbacks are interactive through the bridge. The CLI JSONL output and SDK event list arrive after the run. Timeouts do not guarantee termination of every descendant process or blocking host callback.

What should I verify before shipping an agent?

Test the actual model endpoint and deployment environment, grant only the tools needed, and validate the resulting files or business outcomes. A completed run is not proof that an answer is correct.
