01 / THE EXECUTION LOOP

From model action
to tool result.

The model proposes an action. MOTE checks permission, runs the tool, and returns its observation to the model. The loop stops when the run completes, fails, or reaches a limit.

01

Connect your model

Configure a supported provider or an OpenAI-compatible endpoint. The model can run locally or remotely.

MODEL → ACTION
02

Choose the tools

Use built-in file tools or register a function in your application. Grant each tool by name, and allow only what the task needs.

EXPLICIT CAPABILITIES
03

Set run limits

Limit iterations, tool calls, elapsed time, and observation size. When the run ends, inspect its events and check the output.

OBSERVE → VALIDATE
Permissions are not a sandbox. Tools and callbacks run with the host application's privileges. Isolate untrusted workloads outside MOTE.

import (
    "context"
    "log"
    "strings"
    "time"

    mote "github.com/danny-dis/MOTE/sdk/go"
)

func runAgent() {
ctx, cancel := context.WithTimeout(context.Background(), 150*time.Second)
defer cancel()

result, err := (&mote.Client{Binary: "./mote-bridge"}).Run(
    ctx,
    mote.Manifest{
        Name: "my-agent",
        Capabilities: []string{"uppercase"},
        Models: []mote.ModelConfig{{
            Provider: "openai-compatible",
            Model: "your-model",
            Endpoint: "http://localhost:8080/v1/chat/completions",
        }},
    },
    `Call uppercase with {"text":"hello"}, then complete.`,
    map[string]mote.Tool{
        "uppercase": {
            Description: "Return uppercase text.",
            Handler: func(ctx context.Context, input map[string]any) (string, error) {
                return strings.ToUpper(input["text"].(string)), nil
            },
        },
    },
)
if err != nil { log.Fatal(err) }
if !result.Success() { log.Fatal("Agent run failed") }
}

BEFORE YOU RUN AN AGENT

Common questions.

Is MOTE an AI model?

No. MOTE runs tasks using a model you connect through a supported provider or local endpoint. You arrange provider access and credentials, cover any model costs, and choose a model that meets your needs.

Do I need to install Rust?

The downloadable CLI and bridge run without a Rust toolchain. Python and TypeScript applications can use the prebuilt bridge. You need Rust to compile from source or embed the library.

Can it run untrusted code safely?

MOTE does not provide an OS sandbox. Capabilities limit which tools it can call; shell commands and callbacks still run with the host's privileges. Use an isolated account, container, or VM suited to your workload.

When do callbacks run and events arrive?

The bridge calls your tool handlers during a run. CLI JSONL output and SDK events arrive after it ends. A timeout does not guarantee that every descendant process or blocking host callback has stopped.

What should I verify before shipping an agent?

Test against the model endpoint and environment you will deploy. Grant only the tools the task needs, then check the resulting files or business outcomes. Completion alone does not prove the output is correct.
